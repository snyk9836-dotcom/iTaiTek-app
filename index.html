الوضع:

MODE تنقل بين 6 أوضاع (الوقت، المنبه، ستوب واتش، التاريخ، مؤقت، رقم الحظ). بالمؤقت: RESET يزيد دقيقة وSTART يبدأ. برقم الحظ: START يرمي، وLIGHT إضاءة. بالمنبه: START ساعة، RESET دقيقة، واضغط ALM للتشغيل.

برمج الساعة

اكتب JavaScript واضغط تشغيل. الأوامر المتاحة:

show(أعلى, وسط, أسفل) تعرض أرقام (0 إلى 99) أو null لفراغ

setDay(0..6) اليوم المضيء (0 = SU)، light(true) الإضاءة، beep() صوت، play(1..98) أي صوت من الـ 98 (أو "win")، tone(1000, 200) نغمة بتردد ومدة بالميلي ثانية

onButton("START", fn) تغيّر وظيفة الزر (LIGHT / MODE / START / RESET)

every(ms, fn) تكرر كل مدة، stop() توقف التكرار، alarm(true) رمز المنبه

ضيف الساعة للشاشة الرئيسية

أندرويد (كروم): اضغط النقاط الثلاث، ثم «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

آيفون (سفاري): اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».

بعدها تفتح من أيقونة مثل أي تطبيق، وتحتاج إنترنت لأول فتح.
